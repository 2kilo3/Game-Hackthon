时空管理局｜运行与体验说明
AI 游戏作品 · 不重要队

一、开始体验
1. 将整个“时空管理局”文件夹保存到本地。如收到压缩包，请先完整解压，不要在压缩包预览中运行。
2. 双击同一文件夹中的“时空管理局_剧情完整版.exe”。
3. 在主菜单选择“开始游戏”，按屏幕提示体验。
无需安装 Godot、Python、Node.js 或其他开发工具。游戏资源已嵌入 EXE。

二、账号与网络
本作品无需登录，不涉及测试账号；无需 API 密钥、付费账号、联网或在线模型服务。
AI 用于开发与素材制作，游戏运行时由本地程序执行战斗、剧情和时空机制。

三、运行环境
平台：Windows x86_64（64 位）；建议 Windows 10/11。
图形：支持 OpenGL 3.3 的显卡及正确安装的显卡驱动。
空间：建议预留 500 MB；使用键盘操作，菜单和设置支持鼠标。
本文件为 Windows 程序，不能在 macOS、Linux、手机上直接运行。
现有项目记录的运行检查来自 Windows 开发电脑，Windows 10 和其他设备仍需实测，建议平台不等于已完成全部兼容性验证。

四、默认操作
WASD / 方向键：移动
J：普通攻击
K：格挡
Shift / L：闪避
R：切换现代与未来
Q：钩爪（拾取并解锁后使用）
Tab：天赋界面
Esc：游戏内按键设置；对白期间关闭当前段落
Enter / Space：推进对白
Enter / Esc：在“游戏结束”画面返回主菜单
按键可在设置中调整；如果键位已被修改，可恢复默认设置。

五、推荐评审体验流程
开始游戏及开场对白 → 现代场景移动、攻击、格挡与闪避 → 按进度拾取钩爪并查看天赋 → R 切换现代与未来 → 观察跨时空因果机制 → 未来 Boss 战与结局。
核心机制示例：在现代靠近花盆，按 J 攻击直至打碎，然后切换至未来；对应能量桩会激活，并在未来 Boss 登场、存活且进入范围时发起助攻。可与未打碎花盆对应的能量桩对照体验。
倒地后自动时间回溯；开始新游戏会重置本局。游戏按局运行，请预留连续体验时间。未来 Boss 战后出现“未完待续”和“游戏结束”，可返回主菜单重开。

六、常见问题
1. 黑屏或提示图形不支持：核对显卡是否支持 OpenGL 3.3，并安装电脑或显卡厂商驱动。远程桌面和基础显示驱动可能不提供所需图形能力。
2. 找不到资源或文件损坏：重新完整解压。请保留本文件夹中的程序及引擎、字体版权声明。
3. 按键无效：点击游戏窗口使其获得焦点，再检查按键设置。
4. 无响应：关闭游戏后重新启动；重开会从头开始。
5. 标题栏显示“2.5D Pixel Demo”：这是工程原名，主菜单中的“时空管理局”为本作品名称。
6. 系统阻止启动：记录提示交由作品提供者核查；不要关闭系统安全防护。
